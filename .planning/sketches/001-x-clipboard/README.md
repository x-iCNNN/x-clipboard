# X Clipboard 全页面设计原型

本轮仅交付设计，等待用户确认后再开发 Rust + GPUI Kit 原生应用。

入口：仓库 `design/index.html` 为渲染图库；本目录 `index.html` 为可点击原型。可直接使用浏览器打开，无构建依赖，无网络资源。

原型工具条可以切换页面、主题、操作系统和窗口宽度。所有记录均为示例数据；粘贴、加密、系统权限和快捷键接管仅演示界面反馈，不操作真实系统。设置保存在当前浏览器的原型专用 localStorage 中，可用“重置演示”恢复。

交互重点：

- 在快捷面板中搜索，点击眼睛展开预览；星形收藏、图钉置顶均可操作。
- 记录单击选中、双击模拟回贴；列表焦点下 Enter 回贴、Shift+Enter 纯文本回贴、Space 预览。Esc 先关闭弹窗/预览，再隐藏面板。
- 更多菜单包含“模拟再次复制”，用于查看去重与重新排序效果。
- 管理窗口提供分类、多选、批量删除和保护收藏/置顶的清空流程。
- 快捷键设置支持录制、保留键冲突提示、取消和恢复默认。
- 用页面选择器查看首次使用、存储错误、权限提示、预览失效和托盘菜单等状态。

状态：待用户确认。浅色、深色以及系统变体均保留，不将任何变体标为已验收。
