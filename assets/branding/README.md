# X Clipboard 应用标识

原创“守护剪贴板”图标：圆形暖黄背景、白色剪贴板、三行内容。参考火绒图标的黄色与简洁视觉，不使用其火焰图形或商标。主色 #F5BC21，内容线 #D99600。

- app-icon.svg：彩色矢量母版。
- app-icon-mono.svg：单色展示母版。
- PNG：16/24/32/48/64/128/256/512/1024px，透明底。
- app-icon.ico：Windows 多尺寸应用图标。
- app-icon.icns：macOS 图标容器。

矢量可编辑；PNG由 `cargo run --locked --example branding_assets` 渲染；ICO/ICNS由Pillow从1024px PNG生成。图标为本项目原创，可随项目使用和修改。
