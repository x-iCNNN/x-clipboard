# WebDAV 加密同步

在“设置 → 同步”填写 WebDAV 目录、登录账号、登录密码和独立的同步密码，点击“保存并同步”。其他设备填写相同目录和相同同步密码，即可合并历史。凭据只在客户端输入，不需要提供给项目维护者。

目录必须已存在且可读写，地址使用 HTTPS。仅 `localhost` / 回环地址允许 HTTP，供本机测试使用。当前支持 HTTP Basic 登录；服务需支持标准 MKCOL、GET、HEAD、PUT、强 ETag、If-Match 和 If-None-Match 条件写入。重定向不会自动跟随，请填写服务实际的 WebDAV 目录地址。

同步密码至少 12 个字符，应选择足够强且独立的密码。它不同于 WebDAV 登录密码，不会发送给服务器。首次同步创建加密空间；其他设备密码不匹配时停止同步，不会重建或覆盖远端空间。遗失同步密码后无法从服务器恢复内容。改变已有空间的加密密码不属于本版功能；如需更换，请使用新目录并在各设备重新配置。

## 行为

- 支持文本、富文本、图片、多格式载荷、文件/文件夹路径引用，以及置顶、收藏和主动删除。
- 文件记录不上传实际文件或文件夹内容。其他设备不存在相同路径时，仍按原有“文件失效”逻辑处理。
- 设备的主题、快捷键、容量、排除规则、登录设置和同步凭据不参与跨设备同步。
- 启用自动同步后，启动时同步，此后每分钟检查一次；关闭自动同步后仍可点击“立即同步”。网络任务在后台运行。
- 相同内容按原有格式指纹去重，不修剪空白，不把不同格式合并为纯文本。导入内容不会写入系统剪贴板或自动粘贴。
- 置顶与收藏分别合并，避免两台设备同时操作不同标记时相互覆盖。冲突使用持久化逻辑时钟与设备 ID 确定胜者，不依赖设备墙上时钟一致。
- 主动删除/清空以删除标记同步，旧设备重连不会复活已删除内容；之后明确重新复制可重新加入。
- 本机条数/容量清理仅影响本机，不传播为全局删除；相同版本的已清理记录不会每分钟反复下载。远端重新复制或新置顶/收藏的记录可再次进入本机。
- 同步失败保留本机数据，自动同步下次重试。并发写入冲突会重新读取并合并，最多重试四次；持续竞争会显示错误，允许手动重试。

## 存储协议与边界

本机配置（包括 WebDAV 登录密码和同步密码）、设备标识、逻辑时钟、删除与容量清理状态存放在现有加密 Turso 数据库中。数据库密钥继续由本机操作系统保护，不上传原始数据库或本机密钥。

远端使用独立的 `x-clipboard-v1/` 子目录：`index.bin` 为加密索引，`blobs/` 为不可变的加密内容块。Argon2id（64 MiB、2 次、单通道）从同步密码和随机空间盐派生密钥；XChaCha20-Poly1305 使用随机 24 字节 nonce 和用途关联数据加密认证。文件名由密钥和格式指纹派生，正文和标记不会明文出现在目录名或文件中。

先写入内容块，再通过 ETag 条件写入发布索引。索引冲突不会无条件覆盖远端。导入单条记录和本机编辑各自事务化；同一数据库的后台同步写入与剪贴板写入串行提交，网络等待不持有数据库写锁。明文载荷只在内存中处理，不写入临时文件。

删除是逻辑删除。删除标记及无引用密文块暂不做远端垃圾回收，避免并发设备重新引用时误删内容；因此远端空间不会随本机容量上限自动缩小。本版单个空间最多 100,000 个记录/删除标记，索引最大 64 MiB，内容格式仍遵守本机单次复制 64 MiB 限制；超过限制会报错，不截断后覆盖。同步是多设备合并，不替代离线备份或安全擦除工具。

## 验证

本机故障注入测试覆盖并发首写、ETag 冲突、离线删除重连、独立标记合并、重新复制、容量清理、密码错误、认证失败、损坏密文、上传失败及加密配置重开。

独立服务器探针使用 WsgiDAV / cheroot，测试凭据仅用于回环隔离目录：

```powershell
python -m pip install WsgiDAV cheroot
python scripts/webdav-test-server.py --root test-data/webdav-server --port 0
# 使用服务器输出的回环 URL：
cargo run --locked --no-default-features --example webdav_probe -- http://127.0.0.1:<port>/
```

探针验证真实 Basic 认证、文本/富文本/图片/文件引用、后台启动同步、真实 60 秒周期、关闭自动同步后手动同步和捕获并发。商用 WebDAV 服务的账号、配额和认证策略各异，本记录不代表已验证所有服务商或真实用户账号。
