# 设计交付说明

原型已于 2026-10-24 获得用户确认，见 [确认记录](APPROVAL.md)。以下记录 HTML 设计交付，不替代 [原生验证](../docs/NATIVE-VALIDATION.md)。

## 本轮交付

- 45 个 Windows 页面或状态，各提供浅色和深色版本，包含标题栏窗口菜单。
- macOS、Linux 各补充管理窗口、快捷面板、通用设置的明暗主题版本。
- 合计 102 张 PNG，按 2× 像素密度渲染；全部为独立完整窗口，不是拼贴或裁切图。
- 可点击 HTML 原型、离线渲染图库、自动化交互验收与布局检查报告。

`index.html` 是评审入口；页面搜索、主题和系统筛选帮助定位对应图。点击缩略图放大，左右方向键切换，Esc 关闭。每张图可直接进入对应交互原型。

## 可操作演示

| 流程 | 原型中的操作 |
|---|---|
| 快速回贴 | 单击选中，双击或列表焦点下 Enter 模拟回贴；Shift+Enter 模拟纯文本回贴 |
| 预览 | 点击记录眼睛按钮展开侧边面板；小屏幕切换为单面板并提供返回 |
| 整理 | 图钉、星形按钮切换置顶与收藏；管理窗口支持多选和删除 |
| 去重与排序 | 更多菜单 → 模拟再次复制，记录条数保持不变，移动到本分区顶部 |
| 清空 | 默认保留置顶与收藏，勾选后才包含受保护内容 |
| 快捷键 | 设置 → 快捷键，点击当前组合后录入，支持冲突提示和恢复默认 |
| 表情与符号 | 分类、搜索、点击插入反馈 |
| 设置 | 主题、密度、启动、暂停、容量上限和排除应用均可操作 |
| 异常状态 | 工具条页面选择器可直达文件失效、权限不足、密钥不可用、保存失败等状态 |

原型设置仅写入专用浏览器 localStorage。点击“重置演示”恢复初始数据。记录数据本身不做持久化。

## 视觉约定

第三轮根据浏览器批注改为完整宽导航；标题栏、状态栏与设置分组继续参考火绒及 `D:\code\r\x-bls-workspace`。最新批注优先于第二轮窄图标导航。

- 紧凑列表优先，鼠标主要操作直接可见；右键/更多菜单只放次要动作。
- 主窗口为 200px 图标＋文字导航，显示记录数量；内容区 46px titlebar、52px 底部状态栏，左侧文字设置入口与导航对齐。小于 520px 的预览仍折叠为图标，以保证操作区可用。
- 第四轮修正：首次使用引导的左栏贯穿窗口高度，titlebar 放入右侧内容区；原有四步内容、文案和交互保持不变。
- 设置窗口使用 180px 侧栏，标题与控件分组置于内容区；圆角面板、单层分隔线、控件说明参考 BLS 的设置页。
- titlebar 右侧依次为主题切换、窗口菜单、分隔线、窗口控制；Windows 控制为 32×30，主题/菜单按钮为 30×30。macOS 窗口按钮位于整个窗口左上角，主窗口和设置窗口由侧栏顶部承载。
- 标题栏菜单直接锚定到触发按钮，右边缘对齐、下方间距 6px；三平台和窗口缩放后均保持对齐。标题栏菜单不提供退出项。
- 青绿色代表主要操作、当前导航和健康状态；收藏使用暖色，错误使用红色。
- 共享文字与图标体系，系统窗口按钮遵循 Windows、macOS、Linux 习惯。
- 快捷面板逻辑尺寸 440×600，侧边预览 480×600；管理窗口 1120×760。
- 渲染图中的长设置页展开全部内容；原型在标准窗口内滚动。
- HTML 渲染图用于确认布局与交互，不等同于 GPUI 原生像素验收。

参考证据与对应关系见 [LAYOUT-REFERENCE.md](LAYOUT-REFERENCE.md)。

## 重新渲染与验证

需要 Node.js、Playwright 和本地 Chromium/Chrome。脚本会优先加载本地 `playwright`，其次使用 Codex 捆绑运行时。可通过 `PLAYWRIGHT_MODULE_PATH` 和 `CHROME_PATH` 指定其他安装。

```powershell
node design/tools/render.cjs
node design/tools/verify.cjs
```

生成文件：

- `render-manifest.json` / `render-manifest.js`：图片清单与布局检查结果。
- `verification.json`：交互验收结果。
- `renders/`：按系统和主题分组的 PNG。

## 验证边界

本轮检查 HTML 原型、布局和示例数据交互。未执行 Rust 编译、系统级复制粘贴、Win+V 接管、Turso 加密和跨平台原生运行测试；这些必须在设计确认后的实现阶段验收。

确认关口来自用户批准计划中的“完整 UI/UX 渲染图与可点击原型 → 用户确认 → 原生功能实现”。本轮不跳过此关口。
