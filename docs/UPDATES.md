# 安装与在线更新

从 [GitHub Releases](https://github.com/x-iCNNN/x-clipboard/releases) 获取 Windows x64 安装版或便携版。安装版使用项目自己的 Rust / GPUI 界面，可输入或浏览选择安装目录，选择桌面和开始菜单快捷方式，安装完成后可直接启动。

安装仅针对当前 Windows 用户，默认位置为 `%LOCALAPPDATA%\Programs\X Clipboard`，无需管理员权限。自定义位置必须可写；覆盖安装前请从托盘退出旧版。安装版会注册 Windows“已安装的应用”卸载入口。卸载只移除应用文件和对应快捷方式，保留用户数据目录中的加密历史和密钥。安装器和应用目前均未进行代码签名。

## 手动更新

在“设置 → 关于 → 版本更新”点击“检查更新”。发现新版后点击“下载更新”，校验完成后点击“立即重启更新”。应用先完成数据库关闭，独立安装进程等待应用退出，替换文件后重新启动。请勿在更新过程中移动安装目录。

## 自动更新

Windows x64 默认启用，可在同一位置关闭。应用启动并完成本地数据加载后约 20 秒检查一次，之后每 6 小时检查一次。发现新版时在后台下载和校验；在下一次从托盘正常退出应用后安装，不自动重新启动。关闭内容窗口只会保留在后台运行，因此不会触发安装。也可在“关于”页面立即重启安装。

版本信息和 SHA-256 只从此项目的 GitHub API 获取。下载时在后台对 GitHub 直连和多个公共加速站点抽样测速，自动选择线路；下载失败或校验不通过时自动换线，无需手动选择来源。不上传剪贴板内容、数据库、密钥或 WebDAV 凭据。仅接受版本号更高的正式版本，不安装草稿、预发布版本或降级版本。GitHub 元数据无效、API 限流或所有下载线路失败时会显示错误并允许重试。

当前版本号显示在「应用更新」卡片右上角。下载过程中，卡片背景及百分比根据实际收到的文件字节更新；测速和校验阶段单独显示状态。具体线路及验证记录见[更新加速验证](UPDATE-ACCELERATION-VALIDATION.md)。

macOS、Linux 和 Windows ARM64 暂不支持在线安装，可从“GitHub 发布”入口查看下载。

## 发布协议

- Cargo 版本与 Git 标签保持一致，例如 `0.2.0` / `v0.2.0`。
- 更新资产固定命名为 `x-clipboard-v0.2.0-windows-x64.zip`，应用文件位于 ZIP 根目录，包含 `x-clipboard.exe`、`pdfium.dll`、许可和应用说明文件。
- 自定义安装器固定命名为 `x-clipboard-v0.2.0-windows-x64-setup.exe`。单文件包含同一个 ZIP，尾部记录其 SHA-256、长度和格式标记，安装前验证完整性。
- 两种资产均发布独立 `.sha256` 文件；在线更新另外要求 GitHub API 返回的资产 `digest` 为匹配的 `sha256`。
- `scripts/package-windows.ps1 -NoUpx` 构建应用和安装器，打包运行库、许可、校验文件。运行库先通过 `scripts/fetch_pdfium.py --platform win-x64 --output target/release` 获取。
- 推送 `v*` 标签会触发 `.github/workflows/release.yml`，版本匹配、格式、核心测试和安装回滚测试通过后构建并发布。

在线更新仅覆盖白名单中的应用文件，不清理用户目录。替换前保存旧文件，失败时回滚。更新暂存文件和备份保存在数据目录的 `updates/<任务 UUID>/`；`result.txt` 记录安装结果。回滚失败时保留备份供人工恢复。自定义安装器的覆盖安装也采用备份和回滚。

v0.1.0 未内置更新器，因此需要手动下载本次安装版或便携版；从 v0.2.0 起可在线更新。
