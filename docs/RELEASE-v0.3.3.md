# 中文

- ✨ **Feature**：新增 Windows「回贴按键」设置，支持 `Ctrl+V` 和 `Shift+Insert`，自动保存选择。
- 🕷️ **Bug Fix**：支持使用 `Shift+Insert` 向不支持 `Ctrl+V` 的 SSH 终端回贴内容。
- 🔧 **Fix**：修正 Insert 扩展键标志，确保 `Shift+Insert` 正确发送。

# English

- ✨ **Feature**: Added a Windows paste shortcut setting with `Ctrl+V` and `Shift+Insert`, saved automatically.
- 🕷️ **Bug Fix**: Support pasting with `Shift+Insert` into SSH terminals that do not use `Ctrl+V`.
- 🔧 **Fix**: Corrected the Insert extended-key flag so `Shift+Insert` is sent correctly.
