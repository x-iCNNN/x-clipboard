# X Clipboard 已确定的产品与实现约定

状态：产品范围与视觉原型均已于 2026-10-24 确认，见 `APPROVAL.md`；原生进度和验证边界见 `../docs/NATIVE-VALIDATION.md`。

## 产品

- Rust + GPUI Kit 0.8.0；Windows 10/11 x64、macOS 15+ Intel/Apple Silicon、Linux x64。
- Linux 优先 X11 和有数据控制协议的 Wayland。后台记录、全局快捷键、自动粘贴分别检测能力，受限时给出具体提示。
- 常驻托盘，快捷面板与管理窗口分工。Windows Win+V 为硬性验收项；macOS 默认 ⌘⇧V；Linux 默认 Ctrl+Alt+V；均可修改。
- 文本、HTML/RTF、图片、文件和文件夹引用，离线表情、符号。暂不提供在线 GIF、OCR、AI 功能或 Office/音视频内置预览。
- WebDAV 为用户主动配置的可选加密同步；账号在客户端输入，服务器仅保存加密索引和内容块，不上传本机数据库或密钥。范围、冲突与删除语义见 `../docs/WEBDAV.md`。

## 记录语义

- 同一次复制保留多个可支持格式。按内容和格式去重；不修剪空白、不修改大小写、不按纯文本合并格式不同的记录。
- 重复复制更新最后复制时间并升到所在分区顶部。置顶区始终在普通区之前；收藏不改变排序。
- 应用自己写回不新增记录；外部再次复制相同内容正常刷新。
- 默认 10,000 条或 2 GB 内容容量，任一上限触发普通记录按最后复制时间清理。置顶与收藏豁免，受保护内容超限提示而不删除。
- 单条删除和清空不删除原始文件。清空默认保留置顶与收藏；包含受保护内容需要明确选择。
- 历史文件回贴按复制处理，不重放移动文件的旧剪切操作。

## 预览与窗口

- 第三轮依照用户浏览器批注采用 200px 图标＋文字完整导航，保留 46px titlebar、52px 主窗口状态栏、180px 设置侧栏。titlebar 包含主题、窗口菜单和平台习惯的窗口控制；菜单右边缘对齐触发按钮，不提供退出项。参见 `LAYOUT-REFERENCE.md`。

- 点击行内预览按钮展开侧边详情；单击选中；双击 / Enter 回贴；Shift+Enter 纯文本；Space 在列表焦点下预览。
- 搜索输入优先。Esc 依次关闭弹窗、菜单、预览和快捷面板。管理窗口复制仅写系统剪贴板，不向旧窗口自动输入。
- 预览包含文本/代码、Markdown、图片、PDF、文件夹直接子项与文件信息。
- 图片缩放、PDF 翻页与缩放、文本选择复制。仅保存原文件引用，移动/删除/权限不足均具体反馈。
- 普通窗口、管理员窗口、失效目标分别验证回贴。受限制时提示已复制并让用户手动粘贴。

## 原生架构约定

- `ClipboardBackend`：平台事件/变化计数、完整快照、格式读取、写回、目标窗口与能力报告。
- `HistoryStore`：后台事务、去重、时间与分区排序、检索、收藏、清理。数据库操作不进入 UI render 路径。
- `PreviewService`：后台生成、可取消、资源限额；PDFium 处理 PDF；单个预览失败不停止采集。
- `ShortcutService`：Win+V 专门钩子、回调仅投递事件、修改和退出解除接管、不得永久修改系统快捷键配置。
- 多格式内容及时快照、占用重试、有界后台队列，保存中 / 已保存 / 保存失败分别呈现。不对系统禁止读取或读取前已覆盖的内容作可恢复保证。

## 数据与密钥

- Turso 0.8.3 本地加密；记录、图片载荷、持久化预览均加密保存。
- 随机密钥分别由 DPAPI、Keychain、Secret Service 保护。密钥缺失不可新建密钥覆盖旧库，不降级明文。
- 记录条数、内容容量和实际磁盘占用分别展示。目录修改使用原生选择器。
- 不记录正文、密钥、密码或令牌到日志；尊重应用敏感内容标记，支持暂停及来源排除。
- 固定依赖版本；加密重开、错误密钥、异常退出和升级兼容属于发布门槛。

## 后续实施顺序与验收

1. 用户确认这批全页面渲染图和原型后，再开始原生功能实现。
2. 平台验证先覆盖 Win+V、回贴焦点、多格式捕获、加密重开和 macOS/Linux 能力报告。
3. 实现并测试去重、排序、清理、异步存储、预览和快捷键服务，接入经确认的 GPUI 界面。
4. 真实浏览器、Office、记事本和文件管理器验证连续复制、竞争占用、多文件、富文本、权限差异、休眠与重启。
5. 按平台构建和真实运行，采集原生截图。HTML 验证结果不能替代原生与系统级验收。

新项目无旧数据迁移。
