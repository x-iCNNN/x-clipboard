# X Clipboard 设计清单

## 设计方向

第三轮根据浏览器批注，将主窗口改为 200px 图标＋文字完整导航，保留 BLS 风格的 46px 内容区 titlebar、52px 底部状态栏及 180px 设置侧栏。标题栏菜单与触发按钮右边缘对齐，且不提供退出项。保留 macOS 风格的克制视觉与各系统窗口习惯。紧凑快捷面板负责回贴；管理窗口负责检索、整理与设置。青绿色仅用于当前选择、主操作与健康状态。全部演示数据均为虚构。

## 参考与约束

- GPUI Kit 0.8.0 的 Sidebar、List、Input、Dialog、Tabs、Tooltip、Switch 等组件可承接这些布局。
- Windows 10/11、macOS 15+、Linux X11 / 支持数据控制协议的 Wayland。
- 原型用 HTML 展示并输出 PNG；不代表 GPUI 原生功能、系统权限或加密已经实现。
- 用户已确认产品方向，按一套方案提供主题及系统变体，不再额外探索风格。
- 用户要求先确认完整渲染图，原生开发必须等待本批设计的确认。
